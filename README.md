# KOMARU SHOP — обновлённый визуальный прототип

## Запуск
Откройте `index.html` в современном браузере. Для GitHub Pages загрузите содержимое папки `komaru_shop` в корень репозитория (сам ZIP на Pages не запускается).

## Что обновлено
- Полностью переработан интерьер магазина и адаптивная мобильная компоновка.
- Вместо эмодзи покупателей — CSS-персонажи с разными цветами внешности и одежды.
- Добавлены векторные иллюстрации товаров: значки, набор наклеек, кружка, шоппер и брелок.
- Добавлены плавные появления посетителей, лёгкое покачивание продавца, парящие детали и анимация рулетки.
- Сохранена игровая механика диалогов, цены, продаж и репутации.
- Исправлено: покупатель выбирает только товар, который есть в наличии; остаток уменьшается после покупки.
- Сохранение баланса и репутации работает через localStorage.

## Важное ограничение
В исходном ZIP не было оригинальных файлов принтов Мяовл и Комару. Иллюстрации в `assets/art/` — временные авторские векторные макеты для демонстрации интерфейса, а не точные копии ваших оригинальных рисунков. Для точного совпадения замените SVG на исходные изображения персонажей.

## Публикация
Распакуйте ZIP. Откройте папку `komaru_shop` и загрузите **её содержимое** в корень GitHub-репозитория. В корне должны лежать `index.html`, `style.css`, `js/` и `assets/`. В настройках Pages выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`.
